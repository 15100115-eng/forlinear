# NEXT MOVE — ფინანსური დაფა

ვებ-აპლიკაცია, რომელიც ცვლის `NEXT_MOVE - FINANCIAL.xlsx` ფაილს: შეკვეთების მარტივი დამატება, ავტომატური მოგების გათვლა და ანალიტიკა.

## რას აკეთებს

- **დაფა** — წმინდა მოგება, შემოსავალი, ხარჯი, შეკვეთების რაოდენობა, მარჟა, profit share, სხვა შემოსავალი; დიაგრამები თვეების, შეკვეთების და კლიენტების მიხედვით; ხარჯების სტრუქტურა.
- **შეკვეთები** — სია ძებნით და თვის ფილტრით; დამატება / რედაქტირება / დუბლირება / წაშლა.
- **შეკვეთის ფორმა** — დამკვეთი, თარიღი, ჩარიცხული თანხა, გადახდები (ტრანსპორტი, დამხმარეები, სხვა), მასალა (რაოდენობა × ფასი), სწრაფი ჩიპები ხშირი ხარჯებისთვის. მოგება ითვლება მაშინვე, ზუსტად Excel-ის ლოგიკით:
  - `სრული ხარჯი = გადახდები + საშემოსავლო/საპენსიო (30%, თუ ჩართულია) + მასალა`
  - `მოგება = ჩარიცხული თანხა (÷1.18, თუ დღგ-ს შეიცავს) − სრული ხარჯი`
- **ანალიტიკა** — თვიური რეპორტი (წამგებიანი / მომგებიანი შეკვეთები, მოგება, profit share 15%, დარჩენილი მოგება), კლიენტები, ვისზე გადაიხადეთ ყველაზე მეტი, მასალის ხარჯვა, შემოსავლის წყაროები.
- **სხვა შემოსავალი** — საწყობიდან მიღებული ყოველთვიური შემოსავალი და გაყიდული პროდუქცია (ყუთები).
- **საწყობი / მარაგები** — შესყიდვები მომწოდებლების მიხედვით.
- **მარკეტინგი / ხარჯები** — Meta Ads-ის გადახდები და სხვა ოპერაციული ხარჯი (USD → ₾ კურსით პარამეტრებიდან). Meta-ს ბილინგის ფაილის (xlsx/csv) იმპორტი დუბლიკატების გარეშე, ან ავტომატური წამოღება Meta Marketing API-დან.
- **პარამეტრები** — საგადასახადო განაკვეთები, USD კურსი, ენა (ქართული / English), თემა; Excel-ში ექსპორტი, JSON სარეზერვო ასლი და აღდგენა.
- **მობილური** — ქვედა ნავიგაცია, შეკვეთების ბარათები, სრულეკრანიანი ფორმა, დიდი ღილაკები.

Excel-ის ყველა არსებული ჩანაწერი (სექტემბერი და ოქტომბერი 2026, მარაგები, გაყიდვები, საწყობის შემოსავალი) უკვე შეყვანილია საწყის მონაცემებად.

## მონაცემების შენახვა

მონაცემები ინახება ბრაუზერში (`localStorage`). სერვერი არ სჭირდება — აპლიკაცია სტატიკურია და შეიძლება განთავსდეს Vercel-ზე, Netlify-ზე ან GitHub Pages-ზე. რეგულარულად გადმოწერეთ სარეზერვო ასლი (პარამეტრები → მონაცემები).

## Meta Ads-ის ავტომატური წამოღება

`api/meta-spend.js` არის Vercel-ის serverless ფუნქცია, რომელიც Meta Marketing API-დან იღებს დღიურ ხარჯს (`act_<id>/insights`, `time_increment=1`). Vercel-ის პროექტში დაამატეთ Environment Variables:

| ცვლადი | მნიშვნელობა |
|---|---|
| `META_ACCESS_TOKEN` | System User-ის გრძელვადიანი ტოკენი `ads_read` უფლებით (Business Settings → System Users → Generate token) |
| `META_AD_ACCOUNT_ID` | სარეკლამო ანგარიშის ID (ნაგულისხმევად `2134801500794274`) |

შემდეგ „მარკეტინგი / ხარჯები" გვერდზე აირჩიეთ პერიოდი და დააჭირეთ „Meta-დან წამოღება". თითო დღე ინახება `meta-spend-YYYY-MM-DD` რეფერენსით და განმეორებითი წამოღება იმავე პერიოდს ანახლებს, არ აორმაგებს.

> შენიშვნა: API აბრუნებს **დახარჯულ** თანხას დღეების მიხედვით, ბილინგის ფაილი კი **ბარათიდან ჩამოჭრილ** გადახდებს. ერთსა და იმავე პერიოდზე ორივე წყარო არ გამოიყენოთ, თორემ ხარჯი გაორმაგდება.

## გაშვება

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # სტატიკური ბილდი dist/ საქაღალდეში
```

## სტრუქტურა

| ფაილი | დანიშნულება |
|---|---|
| `src/types.ts` | მონაცემთა მოდელი (შეკვეთა, ხარჯის ხაზი, შესყიდვა, გაყიდვა, საწყობის კლიენტი) |
| `src/calc.ts` | მოგების გათვლა, თვიური რეპორტი, ფორმატირება |
| `src/seed.ts` | Excel-იდან გადმოტანილი საწყისი მონაცემები და სწრაფი ჩიპები |
| `src/store.ts` | localStorage შენახვა |
| `src/i18n.ts` | ქართული / ინგლისური ტექსტები |
| `src/export.ts` | Excel (xlsx) და JSON ექსპორტი / იმპორტი |
| `src/components/` | დაფა, შეკვეთები, ფორმა, ანალიტიკა, სხვა შემოსავალი, მარაგები, პარამეტრები |

---

*English:* a static React + Vite app that replaces the NEXT MOVE finance spreadsheet with a dashboard, a quick order-entry form (profit computed live with the spreadsheet's VAT / payout-tax rules), analytics, warehouse income, product sales and supplies, plus Excel/JSON export. Data lives in the browser's localStorage. Switch language in Settings.
